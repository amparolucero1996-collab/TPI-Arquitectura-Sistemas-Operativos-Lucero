# Trabajo Práctico Integrador — Arquitectura y Sistemas Operativos

**Estudiante:** Bárbara Amparo Lucero  
**Carrera:** Tecnicatura Universitaria en Programación — UTN  
**Tema:** Virtualización y administración de Debian 13

## Descripción

Este trabajo presenta la creación y configuración de una máquina virtual con **Debian 13** mediante **Oracle VirtualBox**, utilizando Windows como sistema anfitrión. El propósito es aplicar conceptos de virtualización, administración de recursos, redes, procesos y servicios de Linux.

## Actividades realizadas

- Creación de la máquina virtual e instalación de Debian 13 con entorno MATE.
- Asignación de 2 procesadores virtuales, 2048 MB de RAM y un disco VDI de 25 GB.
- Verificación de la versión del sistema, CPU, memoria, particiones y conectividad de red.
- Instalación y configuración del servidor web Apache2 y publicación de una página HTML personalizada.
- Configuración de NAT y reenvío de puertos para acceder al servidor desde Windows (8080 → 80).
- Administración del servicio Apache2 y consulta de procesos y registros de acceso.
- Configuración de SSH y acceso remoto desde PowerShell (2222 → 22).
- Creación de dos instantáneas de la máquina virtual como puntos de recuperación. No se realizó una prueba de restauración.
